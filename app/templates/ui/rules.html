How an alert gets its label

  1. payload — the alert's own service / app / job / team label matched a Service or Team key. This wins over rules.
  2. rule — one of the rules below matched. Lowest priority number wins; all conditions in a rule must match.
  3. nothing matched → the alert waits on Unlabelled.

Rules apply to alerts arriving from now on. Alerts already stored are only relabelled by Apply rules to stored alerts — an alert that already resolved is never re-sent by Alertmanager, so without that it stays unlabelled for ever.
